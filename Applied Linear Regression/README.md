# Applied Linear Regression Analysis
Application of simple and multiple linear regression techniques in R across three real-world case studies.

## Overview
This project demonstrates the application of ordinary least squares (OLS) regression to real-world datasets, covering model estimation, hypothesis testing, confidence intervals, model diagnostics, and interpretation of results.

## Case Studies
- GDP Growth and Employment Growth (OECD)
- Wealth, Inequality, and Social Intolerance
- Household Income and Voter Turnout

## Methods
- Simple & Multiple Linear Regression
- Hypothesis Testing
- Confidence Intervals
- Model Diagnostics
- Model Comparison

## Tools
R · stats (`lm()`)
